# Pastel Portfolio Starter (React + Vite + Tailwind)
Minimal, playful pastel portfolio starter with light/dark theme toggle.

## Quickstart
```bash
npm install
npm run dev
```
Then open the URL shown in your terminal.

## Tweak
- Edit `src/PastelPortfolioStarter.jsx` -> `DATA` (name, title, projects, email, socials) and `PALETTE` (colors).
- Tailwind is ready via `src/index.css` and `tailwind.config.js`.

## Deploy
Push to GitHub and deploy on Vercel or Netlify.
